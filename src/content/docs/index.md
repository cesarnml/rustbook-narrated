The full text of **The Rust Programming Language** — the [Brown CS "quizzed" edition](https://rust-book.cs.brown.edu),
cloned and rebuilt fresh on every deploy — with:

- a **🔊 Listen** narrator, powered by [Kokoro](https://github.com/hexgrad/kokoro), running 100% in your browser
- the book's own **recall quizzes**, rebuilt as a lightweight Starlight component from the same question data
- **original hands-on exercises** after every chapter — see [Exercises](/exercises/) — each a runnable Cargo
  project that takes about an hour and stays strictly within what that chapter (and the ones before it) has
  actually covered

See [How this site works](/about/) for what's original here versus what's cloned from upstream, and
[`ATTRIBUTION.md`](https://github.com/cesarnml/rustbook-narrated/blob/main/ATTRIBUTION.md) for the full
license breakdown.
